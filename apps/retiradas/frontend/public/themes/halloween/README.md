# Halloween /acompanhamento — assets individuais

Imagens extraídas da prancha de referência e SVGs transparentes criados para overlays.

**Importante:** os recortes WebP têm a resolução disponível na prancha (alguns são pequenos), não são imagens originais em alta resolução. `halloween-main.webp` é panorâmico, mas tem 1672x226. Para exibição em telas grandes, use `cover` com cautela ou gere um cenário 1920x1080 específico.

Os recortes `halloween-card-*.webp` incluem borda e teias; os SVGs permitem sobreposição independente.

Os arquivos de decoração WebP usam transparência aproximada por remoção de fundo preto; confira as bordas ao aplicar.

Estrutura de destino: `apps/retiradas/frontend/public/themes/halloween/`.
