# Christmas 2026

Assets do tema visual do painel `/acompanhamento`.

- Ativacao: Configurar painel > Tema festivo > Natal.
- Desativacao: desmarcar `Tema festivo` no mesmo painel.
- Escopo: somente a classe `is-christmas-2026` da rota de acompanhamento.
- Os arquivos PNG sao os originais do pack; os WebP sao as versoes otimizadas usadas pela interface.
